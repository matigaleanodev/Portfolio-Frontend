# Portfolio Frontend

[English](README.md)

Frontend de portfolio deprecado, creado dentro de Argentina Programa. Se conserva como referencia de aprendizaje; el portfolio actual se desarrolla en los repositorios indicados abajo.

## Stack

Angular · TypeScript · SCSS · Bootstrap.

## Alcance y configuración

La aplicación incluye vistas de perfil, educación, experiencia, habilidades y proyectos. Depende de la URL de API configurada en sus servicios; su backend original es Portfolio-Backend.

## Desarrollo local

Usar un entorno Node.js compatible con package.json y el lockfile de dependencias, cuando exista.

```sh
npm install
npm start
npm run build
npm test
```
